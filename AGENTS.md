# Project Instructions

## Visual Assets

- Before creating or revising any visual asset, read `docs/art-direction.md`.
- Treat that document as the canonical art-direction and Sprite Forge production contract.
- Use Sprite Forge first for production art: `$generate2dsprite` and `$generate2dmap`.
- Use Codex built-in image generation second when Sprite Forge cannot satisfy the brief.
- Use ComfyUI only as a last solution for model-specific identity or difficult consistency problems; do not treat it as the default asset factory.
- SIGNALIS is only a high-level visual reference. Never copy its characters, symbols, UI, rooms, props, palette arrangement, or exact compositions.
- Describe the project's original high-quality, pixel-filtered school-biochemical survival-horror identity directly in prompts.
- Accepted visual assets must hold up at `1280x720` minimum.
- Do not accept generated assets until they pass the art-direction acceptance gate and are tested at runtime scale in Godot.
