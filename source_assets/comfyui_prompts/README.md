# ComfyUI Generation Handoff

This folder contains the current manual-generation handoff:

- `opening-cinematic-prompts.md`: original cinematic plates/video prompts
- `linxi-sprite-prompts.md`: Early T-form Linxi Sprite Forge sheets

The files in `E:\Chrome down\ComfyUI_0000*.mp4` are reference-only and must not be copied into the game or used as direct generation inputs.

After generating an asset, place it in the destination listed in the prompt pack. The next Codex pass can run Sprite Forge postprocessing, integrate the result into Godot, and perform runtime QC.
